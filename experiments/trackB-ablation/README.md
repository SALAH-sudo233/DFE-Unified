# Track B — DF ablation record

## records/fair_comparison_100k.json

Single-pocket (1a9q) ablation record: DF-375k full model vs A0 (no DF) / A3
(no vector attention) / A4 (no triangle bias). Sample size 22–28 per arm.

**Scope limit:** single pocket, small n, training-budget parity not fully
verified. Use only to **select candidate modification points**, not as a causal
ordering or a CrossDocked-100 SOTA claim. The full narrative and the
interaction-residual design decision are in
`../../docs/experiments/trackb-ablation-and-interaction-update.md`.
